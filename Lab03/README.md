# 实验03：函数

对应《实验课件03-函数》：7个课堂示例，5道教材习题（3-7、3-9、3-10、3-13、3-15）。

打开 Lab03.sln，选择 Debug / x64。各题独立项目。

运行检查记录见 run-results.txt。递归 Fibonacci 输入限制为1至40，以控制朴素递归运行时间。除法商超出 short 范围时报告错误。整数幂检查溢出，实数底数0的负指数报告错误。

## 调试记录

课件要求实际使用断点、F11逐语句进入、F10逐过程和变量观察。已完成主要调试观察，实际记录见 debug-observations.md。阶乘循环和 Fibonacci 完整返回过程未逐次记录。

- 阶乘：在 fact(5) 处断点，F11进入，观察 val 和 rec。
- 引用交换：分别进入 swap(a,a) 和 swap(a,b)，观察别名和交换结果。
- 重载：进入三次 abs 和两次 Add，确认对应参数列表。
- 默认参数：进入两次 sum，观察 num 分别为100和10。
- 递归：进入 fib(5) 和 getPower，观察调用堆栈及返回值。

## 课件问答

fact("hello")、fact()、fact(42,10,0)不匹配形参；fact(3.14)可转换为int 3，结果为6，编译器可能给出转换警告。
仅返回类型不同不能区分相同参数的调用。
int Fun(int i,int j=5,int k)缺少尾部参数k的默认值；Init(,20)不能跳过前面的参数。
内联函数的inline不保证实际展开，现代C++允许其函数体包含循环及递归；课件此处属于简化说明。
