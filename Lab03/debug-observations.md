# 实际 Visual Studio 调试记录

## 阶乘
断点设在主函数调用处。F11进入fact，观察到val=5，F10执行后返回值为120，程序正常退出。原函数为单行，尚未逐次记录循环变量。

## 引用交换
输入3和8。在第13行断点处，a=3、b=8。
F11进入swap(a,a)，两个引用v1和v2均为3，条件成立后返回，主函数a=3、b=8。
F10跳过输出，在第15行F11进入swap(a,b)：v1=3、v2=8。
逐步执行：temp赋值后为8；v2=v1后v2=3；v1=temp后v1=8。
Shift+F11返回主函数第16行，确认a=8、b=3。

## 幂函数递归重载
输入2、2.5、3。实际命中getPower(int,int)，x=2，y依次为3、1、0；命中getPower(double,int)，x=2.5，y依次为3、1、0。每层递归增加调用栈帧。static_cast<double>(a)后实际命中double重载，x=2.0、y=3。完整程序正常退出，退出码0。
