# Visual Studio 调试观察

## 5-7 Cat 对象计数

Debug / x64。运行 Task02_Cat，在 Cat.cpp 第 7、12、17、22 行设断点。

- 第一次调用 getNumOfCats() 发生在创建对象之前，由 main.cpp 第 6 行进入。
- 默认构造由 main.cpp 第 8 行触发。在递增语句上按 F10 后，执行位置移至 Cat.cpp 第 8 行。
- 复制构造由 main.cpp 第 11 行触发，命中 Cat.cpp 第 12 行。
- 赋值后的计数读取由 main.cpp 第 14 行触发。此前没有再次命中构造断点。
- 内层和外层作用域结束时分别命中析构断点，调用栈对应 main.cpp 第 15、17 行。
- 每次计数读取均命中静态成员函数的断点。计数数值来自 run-results.txt 的实际输出，依次为 0、1、2、2、1、0。
- 调试运行退出码为 0。
